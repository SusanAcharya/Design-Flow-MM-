# MoneyMitra Product Specification: Home Screen UI, Behavioral Adaptation & End-to-End System Flow

**Document Focus**: Architectural specifications for MoneyMitra's behaviorally adaptive Home Screen, persistent layout scaffolding, state transition engines, and contextual micro-interactions across the user lifecycle.

---

## 1. Global Shell & Navigation Scaffolding

MoneyMitra uses a unified screen container with a fixed, persistent 5-tab Bottom Navigation Bar. The viewport uses dynamic layout scaling based on active user stages without altering primary navigation routes.

```
┌─────────────────────────────────────────────────────────┐
│ GLOBAL HEADER: [Profile / Stage Badge]  [Search] [Alerts]│
├─────────────────────────────────────────────────────────┤
│                                                         │
│                   DYNAMIC HOME VIEWPORT                 │
│         (Adapts Layout Density via Stage Engine)        │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ PERSISTENT NAVBAR:                                      │
│ [ Home ]   [ Market ]   [ Discover ]   [ Portfolio ]  [ More ]│
└─────────────────────────────────────────────────────────┘

```

### Global Header Components (All Stages)

* **Left**: User Profile Avatar with stage-indicator ring (Gray = Stage 0, Blue = Stage 1, Orange = Stage 2, Green = Stage 3/4). Tapping opens **Profile & Level Selection**.
* **Center/Right**:
* **Search (`🔍`)**: Global search bar indexing tickers (`NABIL`), broker codes (`Broker 33`), market news, and learning terms (`WACC`).
* **Notification Bell (`🔔`)**: Contextual alerts (executed orders, dividend credit notifications, circuit warnings).



### Global Bottom Navigation Bar Targets

1. **Home**: Behaviorally adaptive dashboard (detailed in Section 2).
2. **Market**: Dedicated market pulse view featuring the full NEPSE index chart, live floor sheet stream, advance/decline breadth indicators, and gainers/losers lists.
3. **Discover**: Screener engine, sector heatmap, 52-week change filters, and video lesson hub.
4. **Portfolio**: Transaction ledger, holding breakdown, WACC calculator, CGT tax optimization, and audit trails.
5. **More**: App settings, TMS broker credentials, tax statement exports, and manual density locks.

## 3. Behavioral Stage Engine & Diagnostic Logic

Transitions between Home Screen layout densities occur automatically based on behavioral thresholds or manual overrides.

```mermaid
flowchart TD
    AppStart[User Opens MoneyMitra] --> CheckPortfolio{Imported Holdings?}
    
    CheckPortfolio -- 0 Holdings --> CheckBehavior{Analyze Interactions}
    CheckPortfolio -- 1-4 Holdings --> SetStage1[Stage 1: Primary Investor]
    CheckPortfolio -- 5+ Holdings --> CheckTradingFreq{Checks Floor Sheet Daily?}
    
    CheckBehavior -- Views IPOs / C-ASBA --> SetStage0[Stage 0: Explorer]
    CheckBehavior -- Searches Tickers / Order Types --> SetStage2[Stage 2: Secondary Beginner]
    
    CheckTradingFreq -- No --> SetStage3[Stage 3: Value Investor]
    CheckTradingFreq -- Yes --> SetStage4[Stage 4: Active Trader]
    
    subgraph ManualOverride [User Control]
        SetStage0 & SetStage1 & SetStage2 & SetStage3 & SetStage4 --> Settings[Settings: App Density Lock]
    end

```

### Milestone Threshold Specifications

| Transition | Primary Trigger Criteria | Guardrails & Confirmation |
| --- | --- | --- |
| **Stage 0 $\rightarrow$ Stage 1** | User applies for an IPO or adds 1 primary holding. | Automatic toast: *"IPO added! Unlocking primary market view."* |
| **Stage 0/1 $\rightarrow$ Stage 2** | User executes 1+ manual secondary trade or imports 2+ holdings. | Prompt: *"We've updated your home view with live watchlists. [Undo]"* |
| **Stage 2 $\rightarrow$ Stage 3** | User tracks fundamental metrics (P/E, Financials) across 5+ stocks over 7 days. | Toast notification with direct settings override option. |
| **Stage 3 $\rightarrow$ Stage 4** | User views Floor Sheets or Technical Charts 3+ times in a single live session ($11\text{ AM}-3\text{ PM}$). | Toast: *"Active Trader view enabled. Live index & broker feeds attached."* |

## 5. Micro-Interactions & Contextual Modals

MoneyMitra uses contextual bottom sheets rather than full-screen takeovers for secondary data entry and learning modules.

### 1. Metric Explanation Modal (Tap-to-Learn)

* **Trigger**: Tapping any underlined metric badge (`P/E 18.4`, `WACC 462.40`, `EPS 27.85`) across any screen.
* **UI Specs**: A 40% height bottom sheet featuring:
* **Title**: Metric Name + Current Raw Value.
* **Plain Language Translation**: One-sentence operational definition (*"You are paying NPR 18.40 for every NPR 1 of profit generated by NABIL"*).
* **Contextual Benchmarking**: Horizontal slider comparing the stock's value against sector average and overall NEPSE index average.
* **CTA Button**: `[ Open 2-Min Micro Lesson ]` or `[ Got It ]`.



### 2. Market Fluctuation Circuit Breaker Alert Overlay

* **Trigger**: When the NEPSE Index hits $5\%$ or $8\%$ volatility thresholds or an individual stock reaches its daily $15\%$ cap.
* **UI Specs**: A banner floating over the active Home screen:
* **Color Code**: Amber warning for $5\%$ index halts (15-minute suspension); Red warning for $8\%$ halts (market suspended for the remainder of the session).
* **Text**: Explicit status explanation (*"NEPSE Index down -5.02%. Continuous trading suspended for 15 minutes."*).
* **Action Button**: `[ View Circuit Rules ]` opening a brief rule summary sheet.
